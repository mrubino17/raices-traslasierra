# Raíces Traslasierra

Website prototype for a real estate business focused on Traslasierra, Córdoba, Argentina.

**Tagline:** Tu lugar en Traslasierra.

## Project goals

- Establish a distinctive visual identity rooted in the region.
- Design and prototype a responsive real estate website.
- Build an interactive property catalogue and property detail pages.
- Validate the experience before a future WordPress implementation.

## Direction

- **Personality:** approachable, professional, transparent.
- **Visual direction:** contemporary natural, with editorial and architectural influences.
- **Palette:** Forest `#263B32`, Sage `#697D68`, Sand `#D9D0BE`, Ivory `#F4F1E9`, Charcoal `#343631`.
- **Typography:** editorial serif for headings, modern sans-serif for interface and body text.
- **Technology:** semantic HTML, CSS and vanilla JavaScript for the initial prototype.

## Development stages

1. Project brief and visual direction.
2. Homepage layout and responsive design.
3. Property catalogue and filters.
4. Property detail, about and contact pages.
5. Interaction, accessibility and responsive QA.
6. GitHub Pages demo.
7. Planning for WordPress implementation.

## WordPress implementation (future)

The planned content model may include a **Properties** custom post type, taxonomies for location, operation and property type, and custom fields for price, area, features and gallery.

This repository is a static prototype. GitHub Pages does not run PHP or a WordPress database.
